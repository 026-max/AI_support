## この事業の基本戦略（要約）

1. **区の支援スキームに「入り込む」**: 葛飾区は補助金・伴走支援・IT相談を既に持っている。
   競合するのではなく、セミナー登壇・専門家登録・補助金活用支援で区の導線に乗る。
2. **「用途がわからない」を解消する事例ドリブン営業**: 中小企業の最大の障壁は用途不明。
   業種別の具体デモ（見積書作成、SNS投稿、問い合わせ対応など）を見せて売る。
3. **副業サイズの価格設計**: 月額1〜5万円の軽量伴走＋スポット支援。
   大手コンサルの月30万〜には手が出ない層（従業者数人規模）を独占する。
4. **小さく始めて事例を作る**: モニター3社を無償〜低額で支援し、実名事例を確保してから拡大。
