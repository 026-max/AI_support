# 01. 市場調査レポート — 葛飾区 小規模事業者向け AI・DX支援

作成日: 2026-07-06
目的: 葛飾区でAI・DX活用支援事業を立ち上げるにあたり、市場規模・顧客の実態・既存の支援体制（＝競合かつ連携先）・価格相場を把握し、事業機会を特定する。

---

## 1. 葛飾区の事業者構造（市場規模）

令和3年経済センサス-活動調査（令和2年10月時点）ベース:

| 指標 | 数値 |
|------|------|
| 区内事業所数 | **約16,636事業所** |
| 従業者数 | 約128,556人 |
| 業種構成1位 | 卸売業・小売業 |
| 業種構成2位 | 製造業（約2,100工場） |
| 製造業の規模 | **従業者3人以下の工場が約6割** |

### 読み取れること

- 1万6千超の事業所のうち大半が小規模事業者。**「従業員数人・社長がプレイヤー・IT担当者なし」が典型顧客像**。
- 葛飾区は町工場（金属加工、玩具、皮革など）と商店街の区。製造業と小売・サービス業の両方に汎用的に効く支援（事務作業・販促・問い合わせ対応の効率化）は業種を問わず需要がある。
- 仮に区内事業所の**0.1%（約17社）を顧客化するだけで、副業としては十分な事業規模**になる（詳細は02_事業計画書の収支計画）。

## 2. 中小企業のAI・DX導入の実態（顧客の現在地）

2025年の複数調査から:

- 中小企業の**約6割が生成AIを「活用していない・したことがない」**。「日常的に活用」はわずか13%。
- **従業員10人未満の企業では生成AI導入率は10%以下**。規模が小さいほど認知・活用が進んでいない。
- 従業員5人以下の企業でDXを「名称・内容ともに知っている」のは27%にとどまる。
- 導入の最大の障壁は**「用途がわからない」**。ツールの価格や機能ではなく、「自分の商売のどこに使えるのか」がイメージできないことが壁。
- 今後1〜2年の後押し要因: ツールの低価格化、ノーコード化、補助金の継続、人手不足の深刻化。

### 読み取れること（事業機会）

1. **市場はほぼ未開拓**。葛飾区の典型事業者（数人規模）の9割はまだ生成AIを使っていない。
2. 売り方は「AIとは何か」の講義ではなく、**「あなたの業種ならここで使える」という具体デモ・事例の提示**が必要。
3. ツール販売ではなく**伴走**が価値になる。導入して終わりだと定着せず、「期待以下だった」で解約される。
4. 人手不足が営業の追い風。「人を1人雇う代わりに月3万円でAIと私」という訴求が成立する。

## 3. 葛飾区・東京都・国の既存支援体制（競合分析 兼 連携先分析）

### 3-1. 葛飾区（最重要。競合ではなく導線として使う）

区は産業経済課（テクノプラザかつしか1階、青戸7-2-1）を窓口に、かなり充実したデジタル化支援を既に実施している:

| 制度 | 内容 | 事業への示唆 |
|------|------|-------------|
| **デジタル化支援事業費補助金** | 補助率1/2・上限50万円。ソフト・クラウド利用料・ハード（上限20万円）・外注費・**専門家技術指導費**が対象 | 自分の支援料金も「専門家指導費」として補助対象になり得る。実質半額で顧客に提案できる |
| **デジタル化合同セッション** | 区内企業の体験談＋補助金案内＋個別相談会 | 登壇・事例提供者としての関与を狙う。補助金の**申請要件がこのセッションかIT相談の受診**なので、区の導線の入口 |
| **IT相談・IT導入専門相談** | 専門家による無料相談、簡易診断書の発行 | 無料相談と競合しない設計が必要（後述） |
| **デジタル化伴走支援** | 専門家が導入から定着まで支援 | 支援者側として登録できないか要確認（相談員は中小企業診断士・ITコーディネータ等が多い） |

**重要な構造**: 区の補助金は「区の診断を受けたこと」が申請要件。つまり**区の相談窓口が全ての起点**になっている。この導線の外で営業するより、導線の中（セミナー登壇、相談員登録、補助金申請の実務支援）に入る方が圧倒的に効率がよい。

### 3-2. 東京都

- **DX推進支援事業／DX推進助成金**（東京都中小企業振興公社）: アドバイザー派遣＋機器・システム導入経費の助成。年2回募集。
- **中小企業デジタル導入促進補助事業**: デジタルツール導入費の1/2（小規模事業者は2/3）を補助。
- **中小企業デジタルコンシェルジュ**: 都の無料相談ポータル。

### 3-3. 国

- **デジタル化・AI導入補助金2026**（旧IT導入補助金）: ITツール導入費を補助。補助率1/2、小規模事業者は賃上げ要件等で最大4/5、通常枠最大450万円。
- 申請には登録済み「**IT導入支援事業者**」とのパートナーシップが必要。**幹事登録は法人のみ。個人事業主はコンソーシアム構成員としてのみ参加可**。→ 副業個人としては当面「補助金を使う提案・申請サポート」に徹し、法人化後に支援事業者登録を検討。

### 3-4. 民間の競合

| プレイヤー | 価格帯 | 弱み（＝こちらの勝ち筋） |
|-----------|--------|------------------------|
| 大手・中堅DXコンサル | 月30万〜200万円 | 数人規模の事業者には価格が合わず、そもそも相手にしていない |
| ITベンダー・SIer | ツール販売＋導入費 | 自社製品ありきの提案。中立的な相談相手になれない |
| 中小企業診断士・ITコーディネータ | 公的相談は無料〜 | 計画策定寄りで、**実際に手を動かして構築・定着まではやらない**ことが多い |
| フリーランスDXコンサル | 1.5〜3万円/時 | 地域密着・対面での継続伴走をする人は少ない |

**空白地帯**: 「月数万円で、対面で、実際に手を動かして作ってくれて、定着するまで通ってくれる地元の専門家」はほぼ存在しない。ここがポジション。

## 4. 価格相場

- DXコンサル顧問契約の一般相場: 月30〜100万円（中小向けでも月30万〜が多い）
- スポット相談: 1.5〜3万円/時
- フェーズ別: 初期診断50万〜、戦略立案200万〜（いずれも中堅企業向け水準）

→ 葛飾区の典型顧客（数人規模）にはこの相場自体が非現実的。**月1〜5万円の軽量顧問＋5〜15万円のスポット構築**という「相場の1/10価格帯」を副業の低固定費で成立させるのが戦略（詳細は02）。

## 5. 結論: 事業機会の評価

| 評価軸 | 判定 | 根拠 |
|--------|------|------|
| 市場規模 | ◎ | 区内1.6万事業所、9割がAI未着手 |
| 顧客の支払い意欲 | △→○ | 単価は低いが、補助金で実質負担を半減でき、人手不足が切実 |
| 競合 | ◎ | 低価格×伴走×地域密着の空白地帯 |
| 参入のしやすさ | ○ | SaaS実務ノウハウ＋商工会議所との関係が既にある。区の導線に乗れれば集客コストほぼゼロ |
| リスク | 注意 | 副業規程・競業避止（勤務先SaaSとの利益相反）の確認が必須。単価が低いので工数管理を誤ると疲弊する |

**総合判定: 参入価値あり。ただし「単発で売って終わり」ではなく「区の導線×補助金×月額伴走」の組み合わせで設計すること。**
