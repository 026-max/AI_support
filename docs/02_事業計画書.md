# 02. 事業計画書 — 葛飾区 小規模事業者向け AI・DX活用支援

前提: 副業としてスタート（平日夜・土日中心、稼働月30〜40時間）。市場分析は [01_市場調査レポート.md](01_市場調査レポート.md) 参照。

---

## 1. 事業コンセプト

> **「葛飾の小さな会社の、月3万円のデジタル担当」**

- 大手コンサルの戦略資料ではなく、**実際に手を動かして仕組みを作り、使えるようになるまで隣で伴走する**。
- 特定ツールのベンダーではなく**中立な相談相手**。事業者の予算・リテラシーに合うものだけ勧める。
- 業種は問わない。ただし支援テーマは業種横断で共通する事務・販促・顧客対応に絞る（後述）。

### 提供者の強み（差別化の根拠）

1. SaaS企業勤務の現役実務ノウハウ（ツール選定・導入・定着のリアルを知っている）
2. 葛飾区在住 — 対面ですぐ行ける距離感、地元の信頼
3. 商工会議所（東京商工会議所葛飾支部）との連携ルートがある
4. 副業ゆえ固定費ほぼゼロ → 相場の1/10価格で成立する

## 2. ターゲット顧客

| 区分 | ペルソナ | 典型課題 |
|------|---------|---------|
| メイン | 従業員1〜10名の区内事業者（製造・小売・飲食・建設・士業・介護など）。社長50〜60代、IT担当なし、スマホは使える | 見積・請求・日報が紙／Excel属人化、求人が来ない、販促が手つかず、問い合わせ対応に追われる |
| サブ | 従業員10〜30名で「DXしなきゃ」と思っているが何から始めるか分からない企業 | 補助金は聞いたことがあるが申請できない、ツールを入れたが使われていない |

**業種を問わない代わりに、支援テーマを絞る**（汎用支援を成立させるコツ）:

1. **書類仕事の自動化** — 見積書・請求書・報告書・議事録の生成AI活用、クラウド会計連携
2. **販促・情報発信** — SNS投稿・チラシ文面・Googleビジネスプロフィール・簡易HP
3. **顧客対応** — 問い合わせテンプレ、LINE公式、予約管理
4. **社内の情報共有** — 紙→クラウド化、写真報告、チャット導入
5. **補助金を使った導入設計** — 区・都・国の補助金に乗せる

## 3. サービスメニューと価格

### 導線設計（フロント→バックエンド）

```
無料セミナー（商工会議所・区連携）
  → 無料/低額の「AI・デジタル健康診断」（60分＋診断レポート）
    → スポット支援（1テーマ作り切り）
      → 月額伴走（顧問）  ← 収益の柱
```

### メニュー表

| メニュー | 内容 | 価格（税別） |
|---------|------|------------|
| A. セミナー・勉強会 | 商工会議所・団体向け90分「明日から使える生成AI」 | 3〜5万円/回（連携先によっては無料で集客目的） |
| B. AI・デジタル健康診断 | 60分ヒアリング＋診断レポート＋おすすめ3施策 | 初回無料 → 2回目以降 1万円 |
| C. スポット支援 | 1テーマを作り切る（例: 見積書のAI下書き環境構築、LINE公式開設、Googleビジネスプロフィール整備）。2〜3回訪問 | 5〜15万円/テーマ |
| D. 月額伴走（ライト） | 月1回訪問（90分）＋チャット相談無制限 | 月2万円 |
| E. 月額伴走（スタンダード） | 月2回訪問＋チャット＋小規模な構築作業込み | 月4万円 |
| F. 補助金活用サポート | 区・都・国の補助金の選定＋申請書類の作成支援（C/D/Eに付随） | 5万円/件 または 成功報酬（採択額の10%目安） |

※ 区の「デジタル化支援事業費補助金」は専門家指導費・外注費が補助対象（1/2・上限50万円）。**CやEの費用自体を補助に乗せて実質半額**で提案できるのが最大の営業武器。
※ 補助金申請の「代行」は行政書士法等に抵触し得るため、**あくまで事業者本人の申請の支援・助言**に整理する（グレーを避ける。詳細は05）。

## 4. 収支シミュレーション（副業・月30〜40時間稼働）

### 1年目（立ち上げ）

| 項目 | 想定 |
|------|------|
| セミナー | 四半期1回 × 3万円 = 年12万円 |
| 健康診断→スポット | 月0.5件 × 8万円 = 年48万円 |
| 月額伴走 | 年末時点で4社（2万×2、4万×2）= 月12万円到達 |
| **年商** | **約110〜130万円** |
| 経費 | ツール・ドメイン・名刺・交通費・保険 約20万円 |

### 2年目（軌道化）

| 項目 | 想定 |
|------|------|
| 月額伴走 | 8〜10社 = 月25〜35万円 |
| スポット＋セミナー＋補助金サポート | 年80〜100万円 |
| **年商** | **約380〜520万円** |

→ 2年目後半に「本業の年収と比較して独立判断」が現実的なライン。伴走10社×月2回訪問は副業稼働の上限に近いため、**それ以上は法人化・値上げ・チーム化（後述）が必要**。

### 損益分岐の考え方

固定費がほぼゼロなので赤字リスクは小さい。最大のコストは**自分の時間**。
守るべきKPI: **実効時給5,000円以上**（月額2万円プランなら月4時間以内で回す設計）。

## 5. リスクと対応

| リスク | 対応 |
|--------|------|
| 勤務先の副業規程・競業避止 | 就業規則の確認、必要なら副業申請。**勤務先SaaSの顧客・見込み客と重ならない領域設計**。勤務先製品を売らない（利益相反を避ける） |
| 低単価で疲弊 | メニュー外対応をしない。チャット相談はSLAを「翌営業日返信」に明記。テンプレ資産（templates/）を使い回して1件あたり工数を下げる |
| 「効果がない」と言われる | 契約時に効果指標を1つ決める（例: 見積作成時間を1/3に）。健康診断レポートに現状値を記録しておく |
| 顧客のITリテラシーが想定以下 | メニューBで見極めてから受注。スマホしか使えない事業者にはLINE系施策から入る |
| 補助金制度の変更 | 単年度制度前提で毎年4月に05_補助金活用ガイドを更新する運用にする |

## 6. 将来の拡張オプション（2年目以降に判断）

- **法人化** → 国の「デジタル化・AI導入補助金」のIT導入支援事業者（幹事）登録が可能になり、補助金導線を自前で持てる
- 業種特化パッケージ（例: 町工場向け「図面・見積AI」、飲食店向け「予約×SNS」）の商品化
- 他士業（行政書士・税理士・社労士・中小企業診断士）との相互紹介ネットワーク
- 支援内容のnote/YouTube発信 → 区外・オンライン顧問への展開
