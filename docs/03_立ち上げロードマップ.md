## Phase 0: 法的・社内的な地ならし（今月〜1ヶ月）

**ここを飛ばすと後で全部止まる。最優先。**

- [ ] **勤務先の就業規則を確認**（副業可否、届出制か許可制か、競業避止条項の範囲）
- [ ] 必要なら副業申請を提出。**勤務先SaaSの製品・顧客層と支援領域が重ならないことを説明できる資料**を用意しておく
- [ ] 支援で勤務先製品を推奨しない/しがらみなく中立で行く、の方針を自分の中で明文化（利益相反の予防線）
- [ ] 屋号を決める（例: 「かつしかAI・デジタル相談室」のような地域名＋機能名が検索と信頼に効く）
- [ ] **開業届＋青色申告承認申請書**を税務署に提出（開業日から1ヶ月以内/青色は2ヶ月以内。freee・マネーフォワードの無料作成ツールで15分）
- [ ] 事業用の銀行口座・クレジットカードを分ける
- [ ] インボイス登録は**当面見送りで可**（顧客は小規模事業者中心で免税事業者も多い。課税事業者の顧問先が増えたら再判断）
- [ ] 損害賠償保険を検討（フリーランス協会のベネフィットプラン等。情報漏えい・納品物瑕疵をカバー）

## Phase 1: 商品と看板を作る（1〜2ヶ月目）

- [ ] サービスメニュー・価格を確定（[02_事業計画書.md](02_事業計画書.md) 3章をベースに）
- [ ] 1枚もののLP（ペライチ/STUDIO等）と名刺を作成。肩書きは「AI・デジタル活用支援」＋屋号
- [ ] [templates/ヒアリングシート.md](../templates/ヒアリングシート.md)、[templates/デジタル化診断チェックリスト.md](../templates/デジタル化診断チェックリスト.md) を印刷して持ち歩ける形に
- [ ] **業種別デモを3本作る**（営業の最重要武器。「用途がわからない」を一撃で壊す）
  - [ ] 製造業向け: 手書きメモ→AIで見積書下書き
  - [ ] 飲食・小売向け: 商品写真1枚→SNS投稿文・Googleビジネス投稿を自動生成
  - [ ] サービス業向け: 問い合わせメール→返信文案の自動生成
- [ ] 簡易な業務委託契約書・秘密保持の雛形を用意（顧客の売上情報・顧客情報を扱うため必須）
- [ ] 生成AIの利用ポリシー雛形（顧客に渡す用: 入力してよい情報/ダメな情報）を作成

## Phase 2: 実績ゼロを壊す — モニター獲得（2〜4ヶ月目）

- [ ] 知人・地元のつながりから**モニター3社**を獲得（無料〜3万円、その代わり実名事例化を許諾してもらう）
- [ ] 各モニターで「Before→After」を数値で記録（例: 見積作成 60分→15分）
- [ ] 事例を1社1枚のPDFにまとめる（写真＋社長のコメント付き）
- [ ] 事例をLP・noteに掲載開始

## Phase 3: 区・商工会議所の導線に乗る（3〜6ヶ月目）

- [ ] **東京商工会議所 葛飾支部**の担当者にセミナー企画を持ち込む（[templates/セミナー企画書_生成AI入門.md](../templates/セミナー企画書_生成AI入門.md) を持参）
  - ※23区は「商工会」ではなく商工会議所の管轄。葛飾区の場合は東商葛飾支部。既存の人脈をここに接続する
- [ ] 商工会議所の会員になる（会員向け発信・交流会・会報への掲載チャンス）
- [ ] 葛飾区産業経済課（テクノプラザかつしか）に挨拶し、以下を確認:
  - [ ] **デジタル化合同セッション**への関与余地（事例提供、登壇、個別相談員）
  - [ ] **デジタル化伴走支援・IT相談**の専門家登録の要件（中小企業診断士等の資格要否、公募時期）
  - [ ] 顧客に区の補助金を使わせる際の申請フローの実務詳細
- [ ] 葛飾法人会・法人会青年部・地元金融機関（信金）の担当者ともつながる（信金は顧客紹介の宝庫）
- [ ] 月1本のペースで地元事業者向けの発信（note/Instagram/商店街の掲示）を習慣化

## Phase 4: 収益化の型を固める（6〜12ヶ月目）

- [ ] スポット→月額伴走への転換トークを型化（スポット納品時に「使いこなし定着プラン」として提案）
- [ ] 月額顧問 4社を達成
- [ ] 補助金活用サポートを商品として本格提供（[05_補助金活用ガイド.md](05_補助金活用ガイド.md)）
- [ ] 顧客からの紹介制度（紹介1件で顧問1ヶ月割引等）を開始
- [ ] 四半期ごとに実効時給・解約率・紹介数を振り返る

## Phase 5: 拡大判断（12ヶ月目〜）

- [ ] 顧問8社/月商30万円ラインで、以下を判断:
  - [ ] 値上げ（新規顧客から月額+50%）
  - [ ] **法人化** → 国「デジタル化・AI導入補助金」のIT導入支援事業者登録（幹事は法人のみ）
  - [ ] 独立 or 副業継続
- [ ] 中小企業診断士 or ITコーディネータ資格の取得検討（公的相談員ルートが開き、区の伴走支援側に入りやすくなる）
