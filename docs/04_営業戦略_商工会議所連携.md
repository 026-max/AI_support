# 04. 営業戦略 — 商工会議所・区の導線と連携した集客設計

前提: 広告費をかけない。**信頼が既にある場所（商工会議所・区・信金・紹介）に乗る**のが基本方針。
小規模事業者は「知らない業者からの営業」をまず信用しないため、飛び込み・テレアポはやらない。

---

## 1. 集客チャネルの優先順位

| 優先 | チャネル | 施策 | 期待成果 |
|------|---------|------|---------|
| 1 | 東京商工会議所 葛飾支部 | セミナー登壇、会員交流会、会報掲載 | 1回のセミナーで健康診断申込 3〜5件 |
| 2 | 葛飾区の支援導線 | デジタル化合同セッション関与、伴走支援の専門家登録、補助金の活用支援者ポジション | 区のお墨付き＝最強の信用。相談の受け皿として継続流入 |
| 3 | 既存顧客からの紹介 | 事例PDF＋紹介特典 | 2年目以降の主力。商店街・組合内で横に広がる |
| 4 | 地元金融機関（信金） | 支店の渉外担当と関係構築。取引先の困りごとに同席 | 質の高い紹介（金融機関が「行け」と言うと社長は動く） |
| 5 | 葛飾法人会・業種組合・商店街連合 | ミニ勉強会の出前 | セミナーの横展開 |
| 6 | Web発信（note/Instagram/LP） | 事例と「使える小ネタ」を月2本 | 指名検索の受け皿。直接集客は期待しない |

## 2. 商工会議所連携の具体的な進め方

既に連携できる関係があるとのことなので、以下の順で「点→仕組み」にする:

1. **見学**: 支部主催のセミナー・交流会に参加し、どんな事業者が来ているか、既存のIT系講師が誰かを把握
2. **持ち込み**: [templates/セミナー企画書_生成AI入門.md](../templates/セミナー企画書_生成AI入門.md) を担当者へ。ポイントは
   - 講師料は安くてよい（集客が目的）。無料登壇も選択肢
   - 「区の補助金（デジタル化支援事業費補助金）の使い方まで話す」と企画が通りやすい — 商工会議所は会員に補助金を使わせたい
   - 実演中心・持ち帰れるプロンプト集付き、を売りにする
3. **セミナー当日の導線**: アンケートに「無料AI・デジタル健康診断を希望する」チェック欄 → 後日訪問
4. **定例化**: 単発でなく「四半期シリーズ」を提案（入門→販促編→事務効率化編→補助金実践編）
5. **東商のデジタルシフト・DXポータル/専門家派遣の仕組み**に登録できないか支部担当者に確認

## 3. 区の導線への入り込み方

葛飾区の補助金は「区のデジタル化合同セッション or IT相談を受けて診断書類の発行を受けること」が申請要件。つまり:

```
事業者 → 区のセッション/IT相談（無料） → 診断書類 → 補助金申請 → ツール導入・専門家指導
                                                              ↑
                                          ここの「専門家」「外注先」になるのが狙い
```

- 区の無料相談と**戦わない**。無料相談は「何をすべきかの診断」まで。その先の「実際に作る・定着させる」は誰かがやる必要があり、そこが自分の商品。
- 顧客への営業トークも「まず区の無料相談を受けましょう。付き添います。補助金の要件も満たせます」→ 顧客は得をし、区は実績が増え、自分は補助対象の外注先/指導者として入る。**三方よしの型**。
- 産業経済課への挨拶時は「営業」ではなく「区の制度を顧客に使わせたい実務者」として関係を作る。

## 4. セールスの基本フロー（1件ごと）

```
接点（セミナー/紹介） 
→ 無料健康診断60分（templates/ヒアリングシート＋診断チェックリスト）
→ 1週間以内に診断レポート＋提案書（templates/提案書テンプレート）を持参
→ スポット支援（5〜15万円、可能なら区補助金に乗せて実質半額提示）
→ 納品時に月額伴走を提案（「作って終わりだと3ヶ月で元に戻ります」）
```

クロージングの原則:

- **金額は必ず「補助金適用後の実質額」と「時間削減の金額換算」をセットで提示**（例: 「実質7.5万円で、毎月20時間＝約4万円分の作業が消えます」）
- 初回から年間契約を求めない。月額は「いつでもやめられる」で心理障壁を下げる（実際の解約は少ない）
- 決められない社長には「区の補助金は年度予算がなくなり次第終了」という実在の締切を使う

## 5. 発信コンテンツの方針

- ターゲットが読むのは Facebook/Instagram/紙。X や技術ブログではない
- ネタは「葛飾の◯◯業のこんな作業が、こう変わった」の1事例1投稿
- 顔出し・実名・地元感が信頼の全て。ノウハウの出し惜しみはしない（どうせ自分でやれない層が顧客）
