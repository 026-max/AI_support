# 05. 補助金活用ガイド — 顧客提案に使う区・都・国の制度整理

目的: 顧客の自己負担を下げて受注率を上げるための「武器」の整理。
**制度は単年度で変わるため、毎年4月に必ずこのファイルを更新する。**（最終更新: 2026-07）

---

## 1. 3階建ての全体像

| 階層 | 制度 | 補助率/上限 | 使いどころ |
|------|------|------------|-----------|
| 区 | 葛飾区デジタル化支援事業費補助金 | 1/2・上限50万円 | **第一選択**。ハードル最少、専門家指導費も対象 |
| 都 | 中小企業デジタル導入促進補助事業／DX推進助成金（振興公社） | 1/2（小規模2/3）等 | 区の上限を超える規模、または区予算枯渇時 |
| 国 | デジタル化・AI導入補助金2026（旧IT導入補助金） | 1/2〜4/5・通常枠最大450万円 | 大きめのシステム導入。登録IT導入支援事業者経由が必須 |

## 2. 葛飾区デジタル化支援事業費補助金（主力）

- **補助率 1/2、上限50万円**（令和7年度実績。募集は4月〜翌2月末、予算枯渇で早期終了あり）
- 対象経費: ソフトウェア購入費、クラウドサービス利用料、ハードウェア購入費（ソフト導入に伴うもの・上限20万円）、システム構築外注費、キャッシュレス決済機器、**専門家等からの技術指導費**
- **申請要件: 区のデジタル化合同セッションの相談 or IT相談を受け、診断書類の発行を受けていること**
- 窓口: 産業経済課経営支援係（テクノプラザかつしか1階、青戸7-2-1、03-3838-5556）

### 提案パターン（自分の商品との組み合わせ）

| 顧客の状況 | 提案 |
|-----------|------|
| LINE公式＋予約ツールを入れたい | ツール利用料＋自分のスポット支援費（外注費/指導費）を合算して申請 → 実質半額 |
| PCが古くて何もできない | ソフト導入とセットならPC購入も対象（上限20万円）にできる |
| 何から始めるか不明 | まず区のIT相談に同行 → 診断書類ゲット → 補助金前提の提案書を作る |

## 3. 東京都の制度

- **中小企業デジタル導入促進補助事業**（振興公社）: デジタルツール導入費の1/2（小規模事業者・環境配慮ツールは2/3）。Jグランツ申請。
- **DX推進支援事業／DX推進助成金**: アドバイザー支援＋機器・システム導入経費助成。年2回募集（第1回5〜6月、第2回10月頃）。区の50万円では足りない中規模案件向け。
- **中小企業デジタルコンシェルジュ**: 都の無料相談窓口。顧客への「まず相談」導線として紹介可。

## 4. 国: デジタル化・AI導入補助金2026

- 旧IT導入補助金。補助率1/2、**小規模事業者は賃上げ等の要件で最大4/5**、通常枠で最大450万円規模。
- 申請には事務局登録済みの**IT導入支援事業者**とのパートナーシップが必要。
- **幹事登録は法人のみ**（個人事業主はコンソーシアム構成員としてのみ参加可）→ 現状の自分は登録ベンダーの紹介役＋申請サポート役。法人化後に登録を検討。

## 5. コンプライアンス上の注意（重要）

- **申請書類の作成「代行」を業として報酬を得ると行政書士法に抵触するおそれ**（官公署提出書類の作成代理は行政書士の独占業務）。
  - 自分の立ち位置は「**事業計画の内容に関する助言・情報提供・本人申請の伴走**」に整理する
  - 電子申請の操作を代わりにやらない。入力するのは必ず事業者本人
  - 本格的な申請代行案件は提携する行政書士に回す（相互紹介ネットワークの柱にする）
- 成功報酬型の料金は「採択を保証しない」ことを契約書に明記
- 補助金ありきで不要なツールを売らない（返還リスク・信頼毀損）
