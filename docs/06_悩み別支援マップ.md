# 06. 悩み別支援マップ — 「どんな悩みを、どう解決するか」の見える化

営業・診断・提案のすべてで使う中核ドキュメント。
顧客は「DXしたい」とは言わない。**「人が足りない」「時間がない」「客が来ない」と言う。**
その言葉を起点に、こちらが解決方法に翻訳するための対応表。

- 縦から引く: 顧客の悩み → 解決方法（1章・2章）
- 横から引く: 顧客の業種 → 典型的な悩みと最初の一手（3章）
- 商品に落とす: 解決方法 → 自分のどのメニューで売るか（4章）

---

## 2. 悩み別の詳細（診断・提案時はここを見る）

### 悩み1: 書類仕事に時間を取られる（見積・請求・日報・報告書）

- **よくある症状**: 手書き・Excel転記の二度手間／夜や休日に事務作業／過去見積を探せない／請求漏れ
- **解決ステップ**:
  1. 過去の見積・請求のパターンを整理（自分が実施）
  2. 生成AIに「メモ→見積下書き」のプロンプトを業務専用に作り込む
  3. クラウド請求ソフトで発行・管理・入金確認まで一本化
  4. 日報・報告書は音声入力→AI整形の型を渡す
- **効果の目安**: 書類1件60分→15分。週5時間→1.5時間（月約3.5万円分の人件費相当）
- **売り方**: スポット支援8〜12万円＋ツール月額数千円。区補助金で実質半額。定着まで月額ライトを提案

### 悩み2: 電話・問い合わせ対応に追われる

- **よくある症状**: 作業が電話で中断される／営業時間外の問い合わせを取りこぼす／同じ質問に毎回答えている
- **解決ステップ**:
  1. 問い合わせ内容を2週間記録し、よくある質問トップ10を特定（ヒアリングシート3章と連動）
  2. LINE公式アカウント＋自動応答（営業時間・場所・料金はボットで即答）
  3. 残る個別質問は生成AIで返信文案→本人が確認して送信
  4. 予約・注文はフォームやLINEで24時間受付に
- **効果の目安**: 電話対応が1日1時間→20分。夜間の取りこぼしがゼロに
- **売り方**: スポット5〜10万円。飲食・美容・修理業に特に刺さる

### 悩み3: 新規客が来ない（販促が手つかず）

- **よくある症状**: HPが10年前のまま or ない／Googleで検索しても出てこない／チラシ頼み
- **解決ステップ**:
  1. Googleビジネスプロフィールを整備（写真・営業時間・説明文をAIで作成）— 無料で最も効果が高い
  2. 口コミへの返信運用（AIで返信案→承認して投稿）
  3. InstagramかLINEを1つだけ選んで週1投稿（写真1枚→AIが投稿文生成、の型を渡す）
  4. 必要なら1ページの簡易HP（ペライチ等）
- **効果の目安**: 「葛飾 ＋ 業種」検索での表示・電話ボタンのタップ数が計測できるようになる（Before不明→After可視）
- **売り方**: スポット5〜10万円＋運用定着の月額ライト。**成果が数字で見えるので顧問継続率が高い看板商品**

### 悩み4: リピートが増えない・顧客管理ができない

- **よくある症状**: 顧客連絡先が紙の台帳や社長の携帯にだけある／DMを出す手段がない
- **解決ステップ**:
  1. 名刺・台帳・LINEの友だちをスプレッドシートに一元化
  2. LINE公式で月1回の配信（新商品・季節の案内。文面はAI生成）
  3. 来店・購入履歴のメモ運用を決め、常連の「そろそろ来る頃」を見えるように
- **効果の目安**: 配信→来店の反応が数字で見える。DM印刷郵送より低コスト
- **売り方**: 悩み3とセット販売が自然。単体ならスポット5〜8万円

### 悩み5: 求人しても応募が来ない

- **よくある症状**: ハローワークだけ／求人票が「経験者求む」だけで魅力が書かれていない／職場の様子が外から見えない
- **解決ステップ**:
  1. 生成AIで求人票をリライト（仕事の1日の流れ・先輩の声・写真を入れる）
  2. Indeed・Airワーク等の無料枠に掲載
  3. Instagramで「働く様子」を月2回発信（悩み3の運用と共通化）
- **効果の目安**: 応募0→月1〜2件。採用単価は有料媒体の数十万円に対しほぼゼロ円
- **売り方**: スポット5〜8万円。人手不足が切実な製造・建設・介護の入口商品に最適

### 悩み6: 社長しかできない仕事が多い（属人化・事業承継）

- **よくある症状**: 見積の勘所・仕入先との話・機械の癖が全部社長の頭の中／後継者や若手に教える時間がない
- **解決ステップ**:
  1. 社長に話してもらい録音→AIで文字起こし→手順書・判断基準集に整形（「歩くマニュアル化」）
  2. Notion/Googleドキュメントに「会社の頭脳」として蓄積、検索できるように
  3. 若手には「まずAIとこの手順書に聞く」文化を作る
- **効果の目安**: 引き継ぎ資料ゼロ→主要業務の手順書一式。事業承継・急病時のリスク低減
- **売り方**: 月額スタンダード（月4万円）向きの継続テーマ。**承継を控えた事業者への提案が特に有効**

### 悩み7: 紙だらけで情報が探せない

- **よくある症状**: 図面・契約書・FAXがキャビネットに山積み／「あの書類どこ？」が毎日
- **解決ステップ**:
  1. 命名ルールとフォルダ構成を設計（ここが専門家の価値。ツールより先）
  2. スキャンアプリ＋Googleドライブで「今日から発生する書類」をデジタル化（過去分は重要書類のみ）
  3. FAX注文が多い業種はAI-OCRで受注データ化も検討
- **効果の目安**: 書類探し1日30分→数秒。外出先・自宅からも確認可能に
- **売り方**: スポット5〜10万円。地味だが満足度が高く、悩み1・6への展開起点になる

### 悩み8: 数字の把握ができていない

- **よくある症状**: 儲かっているかは年1回の決算で知る／どの商品・客が儲かるか勘
- **解決ステップ**:
  1. クラウド会計導入（税理士との連携を確認しつつ）で記帳を自動化
  2. 月次で見る数字を3つだけ決める（売上・粗利・現金残高）ダッシュボード化
  3. 「値上げ・撤退の判断材料」として月1レビュー（顧問の定例議題にする）
- **効果の目安**: 数字の把握が年1回→月1回10分
- **売り方**: 税理士の領域を侵さない立ち位置に注意。顧問の定例メニューとして組み込む

### 悩み9: 何から始めればいいか分からない

- **解決方法**: これ自体が「AI・デジタル健康診断」（無料60分）の対象。診断チェックリストで採点→本マップから効く順に3つ提案→区のIT相談に同行して補助金要件もクリア
- **売り方**: フロント商品。ここから悩み1〜8のどれかに必ず落ちる

## 5. 参入業種の優先順位（どの業種から入るか）

戦略: **「実績は飲食・小売で速く作り、収益は町工場で積み上げる」二段構え。**

### 第1波（開業〜3ヶ月）: 飲食・小売中心に「AIが主役の事例」を量産する

**注意: 第1波で売るのは「アカウント開設」ではなく「AIの仕組み」。**
Googleビジネス整備やLINE開設それ自体はただの土台工事であり、AI活用支援の事例にならない。
土台が無い顧客には土台工事も提供するが、**商品名・事例・発信の主語は必ずAI側に置く**。

- 商品の建て付け（例: 「AI販促パック」）:
  - 写真1枚→生成AIが投稿文を作る**週次運用の型**（顧客が自走できるプロンプト＋手順書）
  - 口コミへの**AI返信案ワークフロー**（AIが下書き→店主が承認）
  - メニュー説明・プロフィール文・季節キャンペーン文のAI生成
  - Google/LINEの開設・整備は上記を流すための配信面として同梱
- 事例の見せ方も「AIで週1投稿が5分になった」「口コミ返信を全件AI下書きで返せるようになった」とAIを主語にする
- モニター3社の構成は業種でなくテーマで揃える: ①AI販促（飲食/小売）②AI書類仕事（業種不問）③AI問い合わせ対応 — **3事例とも「AI活用」の看板に直結させる**
- 飲食・小売を中心に置く理由は変わらない: 変化が2〜4週間で見え、母数が多く、商店街で伝播する
- 支払い余力は小さいので**ここで稼ごうとしない**。目的は実名事例と紹介の種まき

### 第2波（3ヶ月目〜）: 町工場（製造業）を本命顧客にする

- 葛飾の特色産業（約2,100工場）で、**区・商工会議所の支援導線が製造業に最も厚い**（テクノプラザかつしか＝産業経済課の拠点自体が工業支援施設）
- 悩みが深く財布が別: 見積・図面・FAXの書類仕事は「削減時間×単価」で効果を金額提示しやすく、人手不足・承継は待ったなし
- 承継・属人化テーマ（悩み6）は月額スタンダードの継続契約に直結し、解約されにくい
- 工業会・組合・下請けネットワークで紹介が回る。1社の信頼が数社に化ける
- BtoBなので営業時間内の訪問がしやすい…わけではない点に注意（社長は日中現場）。**夕方以降・土曜訪問は副業スタイルとむしろ相性が良い**

### 併走枠: 建設・職人系

- 人手不足が最も深刻で支払い能力も比較的あり、「現場写真→報告書AI整形」が強烈に刺さる
- 町工場向けの提案がほぼそのまま流用できるため、追加コストなしで受けられる案件として拾う

### 後回しでよい業種

- **士業・スモールオフィス**: 話は早いが自力で始められる層で、単価も伸びにくい。紹介ネットワーク（行政書士・税理士との提携）としての価値が主
- **介護・医療系**: 需要は大きいが個人情報の扱い設計が重く、事例が揃ってから

## 6. 使い方

- **セミナーでは**: 1章の早見表をスライド化し、「うちの話だ」と思わせる → アンケートで該当する悩みに丸をつけてもらう
- **健康診断では**: ヒアリングシート3章（時間の使い方）の結果を本マップの悩み番号に翻訳する
- **提案書では**: 該当する悩みの「Before→After」「効果の目安」をそのまま転記する
- **運用**: 実際の支援で得たBefore→Afterの実測値でこのマップの数値を随時上書きし、事例集に育てる
