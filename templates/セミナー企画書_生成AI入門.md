## 企画概要

| 項目 | 内容 |
|------|------|
| タイトル案 | **「明日の朝から使える生成AI — 人手不足の葛飾の会社のための90分」** |
| 対象 | 区内の小規模事業者・中小企業の経営者、後継者、事務担当者 |
| 形式 | 会場開催90分（講義30分＋実演40分＋質疑・個別相談20分）。PCなしスマホのみで参加可 |
| 定員 | 20〜30名 |
| 講師料 | 貴所規定に準じます（初回は集客実績づくりのため無償でも可） |
| 講師 | ◯◯◯◯（葛飾区在住。SaaS企業で中小企業のITツール導入・活用支援に◯年従事） |

## 開催の狙い（主催者様のメリット）

1. 中小企業の6割が生成AI未活用・10人未満企業では導入1割以下という現状に対し、会員事業者に「最初の一歩」を提供
2. **葛飾区デジタル化支援事業費補助金（1/2・上限50万円）の活用方法まで具体的に案内** — 区の制度利用の後押しに
3. 「ツール販売目的のベンダーセミナー」ではない中立的な内容

## プログラム（90分）

| 時間 | 内容 |
|------|------|
| 0:00-0:10 | なぜ今か: 人手不足と、同業他社はもう始めているという現実（最新調査データ） |
| 0:10-0:30 | 生成AIで変わる3つの仕事（講義）: ①書類仕事 ②販促・SNS ③問い合わせ対応 |
| 0:30-1:10 | **その場で実演**（参加者のスマホでも一緒に）: 手書きメモ→見積書下書き／商品写真1枚→SNS投稿文／クレームメール→返信文案 |
| 1:10-1:20 | 失敗しない始め方: 入力してはいけない情報、無料と有料の違い、区の補助金・相談窓口の使い方 |
| 1:20-1:30 | 質疑応答・個別相談のご案内 |

## 参加者への配布物

- 「そのまま使えるプロンプト集（業種別20本）」A4・4枚
- 葛飾区・都・国の補助金早見表 1枚
- アンケート（希望者に無料の「AI・デジタル健康診断」60分をご案内）

## 講師側で準備するもの / 主催者様へのお願い

- 講師側: スライド、実演環境、配布物一式、事後アンケート集計の共有
- お願い: 会場（プロジェクター＋Wi-Fi）、会員様への告知（会報・メール・チラシ設置）
