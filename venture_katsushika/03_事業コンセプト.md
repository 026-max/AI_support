# 03. 事業コンセプト(本命案の深掘り) — 仮称「まちこうば365」

作成日: 2026-07-12
前提: **リソースは実質1人**(週末+平日夜)。妻の発信・運営参加は「加速装置」であり事業成立の前提に置かない。小さく始めて実証→拡大→地方創生モデルケース化。

---

## 1. コンセプト

### 一言で

> **「祭りは年に1回。まちこうばは365日ここにある。」**
> 玩具の街・葛飾の町工場を、子どもと大人が通年で通える「体験の常設ネットワーク」に変え、
> 祭り(オープンファクトリー)の翌日から次の祭りまでの364日を事業にする、日本初の「オープンファクトリー通年化カンパニー」。

### 何が「めっちゃ面白い」のか

1. **街そのものがテーマパークになる**: 新しいハコは建てない。約2,100あった工場の現場そのものがアトラクション。入場ゲートの代わりに予約サイトがあり、キャストの代わりに本物の職人がいる。
2. **玩具の街で子どもがものづくりをする、という必然**: タカラトミーの地元・全国トップ級の玩具産地で「遊ぶ側から作る側になる」体験。この物語は葛飾でしか成立しない。
3. **全国70産地が真似したくなる**: 「祭りの通年化」は全オープンファクトリー地域の未解決問題。葛飾で型を作れば、運営パッケージ+予約システムごと横展開できる=地方創生モデルケース。

### ビジョン(5年後)

- 葛飾=「子どもがホンモノのものづくりに触れられる街」として首都圏で第一想起される
- 参加工場は「騒音の出る近所の工場」から「うちの子の先生」に変わる(住工共生の解)
- 体験→ファン化→D2C購入→(子どもが大きくなれば)就職・アトツギまでつながる「工場と人の生涯導線」が回る
- 運営モデルを他産地3地域以上に展開し「かつしかモデル」と呼ばれている

## 2. 誰の、何の課題を解くか

| 顧客 | 課題 | 提供価値 |
|------|------|----------|
| 町工場(供給側) | 単発イベントでは売上にならない/住民に理解されない/若者との接点がない/自社では集客・予約・決済ができない | 面倒ごと(集客・予約・決済・保険・進行)を全部こちらが持ち、工場は「技術を見せる」だけで月数万円の副収入と地域ファンを得る |
| 子育て家庭(需要側) | 週末の「意味のある体験」を探している/STEAM的な学びをさせたいが教室は高い・画一的 | 本物の工場で本物の職人から学ぶ、ここでしかできない体験(2,000〜5,000円/回)。かつしかライブファクトリーで有料でも売れる実績は確認済み |
| 葛飾区・東商(行政側) | 工場減少(ピーク比1/4)、住工トラブル、アトツギ不在に打ち手が足りない | 区の施策(見本市・ブランド・ライブファクトリー)の「間を埋める」民間の通年実行部隊になる |

## 3. フェーズ設計 — 1人で回すことを最優先

### Phase 1: 実証(0〜3ヶ月)「月1回の体験会を2社で回す」

- 工場2〜3社×月1回・親子8組限定の体験会。**この規模なら企画・集客・当日運営まで1人で完結する**
- 集客: 自分のSNS+まいぷれ葛飾/葛飾経済新聞など地域メディアへの持ち込み+工場の口コミ。8組ならこれで埋まる
- 予約・決済: 既存SaaS(STORES予約/Peatix等)を使い、開発しない(ITスキルは「作る」より「選んで組む」に使う)
- 検証すること: ①有料で埋まるか ②満足度・リピート意向 ③工場側が「またやりたい」と言うか ④1回あたりの自分の稼働時間

### Phase 2: 通年化(4〜12ヶ月)「まちこうばクラブ(月謝制)」

- 体験会リピーターを月謝制会員に転換(月1〜2回、いろんな工場を回遊する「工場の習い事」)
- 工場を5〜8社に拡大。ここで初めて単発ヘルプ(当日サポーター)や工場側スタッフに運営を部分委譲
- 区・東商に実績を持ち込み、かつしかライブファクトリー/見本市との公式連携を取り付ける

### Phase 3: 重ね掛け(1〜2年)「大人向け・観光・物販」

- 大人向け(工場見学×立石せんべろの半日コース=案D)を追加。企業研修・視察の団体受注も
- 体験で人気の工場から1社選び、D2C商品をクラファン(案B)。体験参加者がそのまま初期顧客になる

### Phase 4: モデル化(2年〜)「かつしかモデルの外販」

- 運営マニュアル+予約/顧客管理の仕組み+工場の口説き方を「産地パッケージ」化し、他地域のオープンファクトリー実行委員会・自治体に販売
- 蓄積した工場ネットワークと信頼を土台に、アトツギ支援(案C)に着手

## 4. 最初の90日プラン(1人・週末+平日夜)

| 週 | やること |
|----|----------|
| 1〜2週 | かつしかライブファクトリー参加企業(彫刻・印刷・椅子張り等の体験実績あり)をリストアップし、体験会の企画書1枚を作って3社にアポ |
| 3〜4週 | 工場2社と条件合意(謝礼折半・定員8組・安全ルール)。レクリエーション保険・特定商取引表記・キャンセル規定を整備 |
| 5〜6週 | 予約ページ公開。地域メディア2〜3件に持ち込み、SNSで告知開始 |
| 7〜8週 | **第1回体験会を催行**。アンケート(満足度・価格受容・リピート意向)を必ず取る |
| 9〜12週 | 第2回催行+振り返り。工場側ヒアリング。数字が立てば区/東商に「通年化構想」を持ち込む |

**工場の口説き方の要点**: 「イベントに出てください」ではなく「**御社の負担は当日2時間だけ。集客も予約も保険もお金の管理も全部こちらがやり、売上の半分をお渡しします**」。ライブファクトリー経験社なら体験設計済みなので追加負担が最小。

## 5. ユニットエコノミクス(粗い試算)

### Phase 1: 体験会1回あたり

| 項目 | 金額 |
|------|------|
| 売上: 8組×3,500円 | 28,000円 |
| 工場謝礼(50%、材料費込み) | ▲14,000円 |
| 保険(レクリエーション保険 約30名分) | ▲1,000円 |
| 決済手数料(約5%) | ▲1,400円 |
| **粗利/回** | **約11,600円** |

→ 月2回でも月2万円強。**Phase 1は稼ぐフェーズではなく、「有料で埋まる証拠」と「工場の信頼」を買うフェーズ**と割り切る(持ち出しほぼゼロで検証できることに価値がある)。

### Phase 2: 月謝制クラブ(12ヶ月後の目標ライン)

| 項目 | 金額 |
|------|------|
| 会員30名×月謝6,600円 | 198,000円/月 |
| 単発体験・大人向け | +50,000円/月 |
| 工場への分配・保険・ツール | ▲120,000円/月 |
| **粗利** | **約13万円/月** |

→ 副業として成立するライン。ここまで実証できたら法人化・調達・補助金(区のデジタル化補助や東京都の創業助成等)を検討する。

## 6. 「1人で回す」オペレーション設計

- **開発しない**: 予約=STORES予約等、決済=同SaaS、顧客管理=スプレッドシート+LINE公式。作り込みはPhase 2以降
- **体験プログラムを作らない**: ライブファクトリーで各工場が既に持つワークショップをそのまま使う。自分の仕事は「編集と流通」
- **月の稼働上限を決める**: 平日夜5h+週末8h=月50h程度に収まる規模(体験会月1〜2回)以上に広げない
- **雇わずに借りる**: 当日ヘルプは工場スタッフ+スポットワーク、広報は地域メディア持ち込み、信用は区・東商の看板を借りる
- **妻(加速装置)が乗ってくれた場合**: 集客リーチが跳ね、親目線の体験改善が入る → Phase 2への移行が半年早まる。ただし乗らなくても上記の通り成立する

## 7. リスクと撤退基準

| リスク | 対策 |
|--------|------|
| 工場が1社も乗らない | ライブファクトリー経験社(体験提供済み)に絞って口説く。区・東商経由の紹介ルートも併用 |
| 事故・ケガ | 保険加入+年齢制限+危険工程は「見るだけ」に設計。工場と安全チェックリストを事前合意 |
| 集客できない | 8組×月1回まで規模を絞っているので、埋まらないなら価格/曜日/内容を変えて再試行(撤退基準参照) |
| 自分の稼働が溢れる | 月50h上限を先に決め、超えるなら拡大せず値上げ・委譲で調整 |

**撤退・方向転換基準(正直に決めておく)**: 90日以内に「工場2社確保」ができない、または体験会を3回やって平均集客が定員の5割未満なら、この形は畳み、工場ネットワークの資産を案B(D2C)か案C(アトツギ)に転用する。

---

## 8. 地方創生モデルケース化のロードマップ骨子

1. **実証の数字を公開する**(体験会の集客率・工場側の収入・リピート率をnote等で発信)→ 他産地から問い合わせが来る状態を作る
2. **区・東商との公式連携**で「かつしか発」の看板を得る(見本市・ライブファクトリーとの共催枠)
3. **運営の型を文書化**(工場の口説き方・安全設計・価格表・予約システム構成)=そのまま外販商品になる
4. **他産地1号案件**(墨田・台東・大田など近隣か、燕三条のような祭り実績地域)で有償導入 → 「かつしかモデル」の完成
